# Coupon Collector's Problem
In this lab, I created a Monte Carlo Simulation to solve the Coupon Collector's Problem on the suit in deck of cards. The Coupon Collector's Problem asks how many random draws it takes to collect all n unique items. In this case I was looking to get the average number of draws it takes to get at least one card from every suit. In my solution, I provided the ability to simulate the problem on a deck of cards both with and without replacement.

## Lab Learning Objectives
1. Fixed arrays – creating, using, and passing to functions.
2. Use enum classes.
3. Breaking logic into functions.
4. Using static casting.
5. Use prototypes (forward declarations) to tell the compiler what our function declarations look like.
